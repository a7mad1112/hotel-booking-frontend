# Hotel Booking - Frontend

The client-side web application for the Hotel Booking & Reservation System, providing an intuitive interface for browsing hotels, searching rooms with live filters, booking stays, and processing payments.

## Related Links

- Backend API Repository: https://github.com/a7mad1112/hotel-booking
- Trello Development Board: https://trello.com/b/edL3w4KO/hotel-booking-system-development-plan
- Interactive Database ERD: https://dbdiagram.io/d/hotel-booking-6aab4010af7c3b0bd1fcf6f2

## Quick Start

1. Install dependencies:
   npm install

2. Configure environment:
   Create a .env file:
   VITE_API_BASE_URL=http://localhost:8080/api

3. Run development server:
   npm run dev
